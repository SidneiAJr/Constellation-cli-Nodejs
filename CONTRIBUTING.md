# CONTRIBUTING — Constellation CLI

Obrigado pelo interesse em contribuir!

---

## Como contribuir

1. Faça um fork do repositório
2. Crie uma branch para sua alteração (`git checkout -b fix/sua-alteracao`)
3. Faça o commit (`git commit -m 'fix: descrição da alteração'`)
4. Abra um Pull Request

---

## Antes de abrir um PR

- Descreva o que foi alterado e o motivo
- Se for uma correção de bug, informe como reproduzir o problema
- Se for uma nova funcionalidade, explique o caso de uso

---

## Análise

Todas as contribuições serão analisadas antes de serem aceitas.
Não há prazo garantido de revisão, mas toda sugestão é bem-vinda.

---

## Contato

Caso prefira, entre em contato antes de abrir o PR para alinhar a ideia.
